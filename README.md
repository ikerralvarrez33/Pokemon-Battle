Pokémon Battle

Proyecto desarrollado en Java para gestionar entrenadores, Pokémon y combates.

¿En qué consiste?

La aplicación permite crear entrenadores y formar sus equipos Pokémon. Cada Pokémon cuenta con sus propios tipos y movimientos, que pueden utilizarse durante los combates.

El proyecto incluye un sistema de combate por turnos donde los jugadores pueden elegir diferentes movimientos y acciones, teniendo en cuenta aspectos como el daño, la defensa y los puntos de vida de los Pokémon.

Funcionalidades
Crear y gestionar entrenadores.
Añadir Pokémon a los equipos.
Gestionar tipos y movimientos.
Elegir el Pokémon que participa en el combate.
Realizar ataques y calcular el daño.
Gestionar la defensa y los puntos de vida.
Realizar combates entre entrenadores.
Realizar pruebas unitarias con JUnit.
Tecnologías
Java
Eclipse
JUnit
Pruebas

El proyecto incluye diferentes pruebas con JUnit para comprobar que las principales funcionalidades funcionan correctamente y detectar posibles errores.

Objetivo

El objetivo del proyecto es practicar programación orientada a objetos en Java y desarrollar la lógica necesaria para gestionar Pokémon, entrenadores y combates.
